# Literature Review Plan
The university requirement is at least 12 meaningfully used sources, including at least 8 scientific publications. Prefer sources from the last five years for rapidly evolving topics while retaining foundational works. Do not count a source unless its content is read and used.
| Topic | What to extract | Critical angle |
|---|---|---|
| Food-image classification | Dataset, classes, top-k metrics | Real-world generalization |
| Portion estimation | Method, error metrics | Occlusion/depth assumptions |
| Image-to-nutrient pipeline | Pipeline, evaluation | Recognition accuracy ≠ calorie accuracy |
| Food datasets | Coverage, labels | Regional dishes and mixed meals |
| Food diary validity | Recall and entry error | Self-report bias |
| Nutrition-app usability | Participants, metrics | Long-term adherence |
| Uncertainty display | Calibration, confirmation | Confidence can be misunderstood |
| Image privacy | Consent, retention | Sensitive routine inferences |
| Nutrition databases | Coverage, provenance | Missing values and regional bias |
| Rule evaluation | Baseline and metrics | Avoid unvalidated health claims |
| On-device ML | Latency, size, battery | Resource vs accuracy trade-off |
| Behavior-change design | Study outcomes | Correlation vs causation |
For each source record author, year, title, venue, DOI/stable URL, method, result, limitations, and how it informs a design decision. Prefer peer-reviewed papers for scientific claims and official documentation for platform capabilities. Include contradictory findings.
