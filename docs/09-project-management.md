# Project Management
Create real tasks in YouTrack or an approved equivalent. These are proposed work items, not existing task IDs.
| Work item | Deliverable | Acceptance criteria | Priority |
|---|---|---|---|
| Requirements/scope | Proposal + requirements | P0 requirements have testable criteria | P0 |
| User research | Interview notes | 3–5 real discussions or approved alternative | P0 |
| Literature review | Evidence table | 12 used sources, 8 scientific | P0 |
| Existing systems | Comparison matrix | 3–5 systems, 6–10 cited criteria | P0 |
| Technology choices | Decision records | 3 key choices, 2–3 alternatives each | P0 |
| Architecture | 3 diagrams | Editable source + readable export | P0 |
| UX prototype | Clickable screens | Key flows work, limitations labelled | P0 |
| Android MVP | Running app | Manual entry demonstrated | P1 |
| Evaluation | Test plan | P0 requirements map to checks | P0 |
| Repository | README and commits | Clear structure, no secrets | P0 |
## Risks
Photo-to-calorie uncertainty; limited time; nutrition-data licensing/coverage; unvalidated user needs; sensitive images/history. Mitigate with user confirmation, prioritization, source review, honest evidence labels and privacy-first design.
Use meaningful commits, real task IDs in branch/commit names once assigned, and supervisor review at agreed checkpoints. Never invent task IDs, approvals or commit history.
