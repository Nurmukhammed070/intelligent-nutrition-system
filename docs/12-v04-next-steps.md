# v0.4 Status and Next Steps

## Implemented in this release
- Name-based food search in the Add Food workflow.
- Nutrition values automatically loaded from the local illustrative food catalogue.
- Portion editing and updated nutrition calculations in the existing review UI.
- English-language fixes, stronger input validation, and added API regression tests.

## Planned, not yet delivered
- Replace illustrative nutrition values with an audited/licensed food composition dataset and record provenance per item.
- Expand and evaluate recipe/meal text parser for ambiguous food descriptions.
- Implement true AI image recognition with a provider adapter and a carefully measured evaluation set.
- Save records in a persistent authenticated backend and build a verified native Android application.
- Collect actual interview evidence and complete peer-reviewed sources before university submission.
